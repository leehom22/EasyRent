Task management app

This is a task management application built with react nodejs and mongodb.

Features:
- user login
- create tasks
- delete tasks
- update tasks
- manage users

Tech stack:
React
Node.js
Express
MongoDB

Installation:
first clone the repository
then install dependencies
then start the server

Frontend:
npm install
npm run dev

Backend:
npm install
npm start

API:
GET /api/tasks
POST /api/tasks
PUT /api/tasks/:id
DELETE /api/tasks/:id
